# 无障碍人工审计协作工作台

源提示词摘要：审计员记录问题、复现步骤、影响人群和严重程度，审核员判断重复或补充证据，开发人员提交修复，复测人员关闭或重新打开问题；所有核心流程可以用键盘完成，并正确管理焦点和错误提示。

## 技术栈

SolidStart、TypeScript、Park UI、Solid Router、TanStack Query、Solid Store、Modular Forms、Zod、Solid i18n primitives。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62025`

## 可用流程

- 创建审计问题，保存复现步骤、影响人群、证据和严重程度。
- 问题按待分诊、修复中、待复测、已关闭和重新打开流转。
- 将重复问题合并到主问题，保留来源关系和操作审计。
- 开发修复与复测结果分开记录，复测失败自动重新打开。
- 支持跳过导航、可见焦点、读屏提示、`N` 快捷键聚焦新建问题、`Ctrl+Enter` 提交。
- 数据保存在 localStorage，Park UI preset 与 Ark UI 可访问交互原语参与界面实现。

## 事件账（多标签页协作）

所有写操作只追加**带编号的事件**（`src/audit/ledger.ts`），当前问题与时间线全部由事件重放得出：

- 建问题、改字段、状态流转、合并重复项均先追加编号事件，再重放生效；时间线按编号排序。
- 多标签页并发：BroadcastChannel + storage 事件同步，事件按 id 去重、按编号排序。字段级乐观并发——后提交一方不盖先提交内容，冲突字段保留两版并标注来源标签页与事件编号。
- 状态机：越界流转一律拒绝并保留原状态，时间线留痕。
- 判定作废：已确认问题被改内容后，已确认判定作废重算、退回待复核（`open`）；重新提交复测时上一轮复测记录清空。
- 合并失败：从最近可用结果恢复，原批次事件保留不动。
- 旧数据升级：首次加载读取 `a11y-audit-v1` 并迁移为事件流，原问题与时间线保留。

自检：`npx tsx src/audit/ledger.selftest.ts`（11 项断言覆盖上述全部规则）。
